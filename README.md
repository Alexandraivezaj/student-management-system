# Database Management Web Application

A full-stack database-driven web application designed to manage student and course information through a structured relational database. The project combines a React frontend with a PHP backend and SQL database to provide an interactive interface for working with student, course, scheduling, and attendance data.

## Features

- Student management and registration
- Course management
- Student scheduling
- Attendance tracking
- Student ranking and listing
- Relational database design
- REST-style backend API
- Interactive React frontend
- Form validation and data handling

## Application Structure

The project is divided into two main components:

### Backend

The `maru` directory contains the PHP backend and database functionality.

Key components include:

- Controllers for students and courses
- Student and Course models
- API routing
- Database configuration
- Input validation
- SQL scripts for database creation and population

### Frontend

The `maru-frontend` directory contains the React-based user interface.

The frontend includes components for:

- Student lists
- Student cards
- Student creation and editing
- Class management
- Scheduling
- Attendance
- Student rankings

## Database Design

The project includes SQL scripts and database design documentation used to define the application's relational data model.

Included files:

- `maru.sql` – database schema
- `maru-erd.html` – entity relationship diagram
- `maru-relational.html` – relational model documentation
